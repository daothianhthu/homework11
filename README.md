# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

## 1. 실험 개요
무작위 정수 데이터(n = 1,000 ~ 20,000)에 대해 삽입 정렬, 쉘 정렬(Shell 기본 간격 n/2), 쉘 정렬(Knuth 간격)을 수행하고 데이터 값 사이의 비교 횟수를 측정하였다. 모든 알고리즘은 동일한 원본 데이터의 복사본을 사용하였고, 정렬 후 오름차순 여부를 검증하였다.

## 2. 측정 결과

| n | 삽입 정렬 | 쉘 (기본) | 쉘 (Knuth) | 삽입/쉘(기본) | 삽입/쉘(Knuth) | Knuth의 감소율 |
|---|---:|---:|---:|---:|---:|---:|
| 1,000 | 248,865 | 15,614 | 14,405 | 15.9배 | 17.3배 | 7.7% |
| 2,000 | 1,027,144 | 38,051 | 32,665 | 27.0배 | 31.4배 | 14.2% |
| 4,000 | 4,033,165 | 86,836 | 77,365 | 46.5배 | 52.1배 | 10.9% |
| 8,000 | 15,812,233 | 200,531 | 175,218 | 78.9배 | 90.2배 | 12.6% |
| 16,000 | 63,916,799 | 489,990 | 420,280 | 130.4배 | 152.1배 | 14.2% |
| 20,000 | 100,265,887 | 623,282 | 529,543 | 160.9배 | 189.3배 | 15.0% |

(Knuth의 감소율 = 기본 간격 대비 비교 횟수가 줄어든 비율)

## 3. 분석

### 3.1 데이터 크기 증가에 따른 비교 횟수 변화
- **삽입 정렬**: n이 2배가 될 때마다 비교 횟수가 약 4배(4.13, 3.93, 3.92, 4.04배)로 증가한다. 이는 O(n²)의 특징이다. 무작위 데이터에서 평균 비교 횟수는 약 n²/4이며, n = 1,000일 때 약 250,000(실측 248,865), n = 20,000일 때 약 1억(실측 100,265,887)으로 이론값과 거의 일치한다.
- **쉘 정렬**: n이 2배가 될 때 비교 횟수는 약 2.3~2.4배(기본 간격), 2.3~2.4배(Knuth)로 증가한다. 증가율이 2.3~2.4배라는 것은 비교 횟수가 대략 n^1.2 ~ n^1.3에 비례한다는 뜻으로, 삽입 정렬(n²)보다 훨씬 완만하다.

### 3.2 삽입 정렬과 쉘 정렬의 성능 차이
- 쉘 정렬이 항상 훨씬 적은 비교로 정렬을 마쳤고, **n이 클수록 격차가 커진다**. n = 1,000에서는 약 16~17배 차이지만 n = 20,000에서는 약 161~189배까지 벌어진다.
- 원인: 삽입 정렬은 원소가 한 번에 한 칸씩만 이동하므로, 멀리 떨어진 위치로 가야 하는 원소는 평균 O(n)번의 비교·이동이 필요하다. 쉘 정렬은 큰 gap으로 먼저 정렬하여 원소를 목표 위치 근처까지 한 번에 크게 이동시킨다. 그 결과 마지막 gap = 1 단계에서는 이미 "거의 정렬된" 배열을 처리하게 되고, 삽입 정렬은 거의 정렬된 입력에서 원소당 비교가 1~2회 수준으로 줄어든다.
- 즉 쉘 정렬은 삽입 정렬의 약점(먼 거리 이동)을 gap으로 보완한 알고리즘이며, 데이터가 커질수록 이 이점이 커진다.

### 3.3 기본 간격(n/2)과 Knuth 수열의 성능 차이
- 모든 n에서 Knuth 수열이 기본 간격보다 비교 횟수가 적었고, 감소율은 7.7%~15.0%였다. 차이는 삽입 정렬 대비 격차(수십~수백 배)에 비하면 작지만, n이 커질수록 대체로 커지는 경향이 있다(n = 20,000에서 15.0%).
- **패스(pass) 수 차이**: 한 번의 gap 패스에서는 결과와 관계없이 최소 (n - gap)번의 비교가 발생한다. n = 20,000에서 기본 간격은 10000, 5000, ..., 2, 1로 **14번**의 패스를, Knuth는 9841, 3280, 1093, 364, 121, 40, 13, 4, 1로 **9번**의 패스를 수행한다. 패스마다 최소 비교 횟수를 합산하면 기본 간격은 약 260,000회, Knuth는 약 165,000회이며, 차이는 약 95,000회이다. 실제 측정 차이(623,282 - 529,543 = 93,739)와 거의 일치하므로, **두 방법의 성능 차이 대부분은 패스 수가 적어 생기는 고정 비용 차이**로 설명된다.
- **gap 사이의 관계**: 기본 간격은 인접한 gap이 서로 2의 배수 관계이거나 공약수가 많아(예: 500, 250), 앞 단계에서 이미 비교된 원소끼리 다시 비교하는 경우가 많다. Knuth 수열(1, 4, 13, 40, ...)은 인접 gap이 서로 약수·배수 관계가 아니어서 다른 원소들이 서로 섞여 비교되므로 정렬 정보가 더 고르게 전파된다.

### 3.4 간격 수열이 쉘 정렬 성능에 영향을 미치는 이유
1. **패스 수**: gap이 너무 촘촘하면(감소 비율이 작으면) 패스가 많아져 최소 비교 비용이 누적되고, 너무 성기면 마지막 gap = 1 단계에서 처리할 무질서가 많이 남는다. Knuth 수열은 약 3배씩 줄어 패스 수와 마지막 단계 부담 사이에서 균형이 좋다.
2. **gap 간의 서로소 성질**: gap들이 공약수를 많이 가지면 서로 다른 부분 수열 사이의 정보 교환이 늦어져, 마지막 gap = 1에서 큰 무질서가 남는다. 이론적으로 기본 간격은 n이 2의 거듭제곱일 때 최악 O(n²)이고, Knuth 수열은 최악 O(n^1.5)로 알려져 있다.
3. 단, 본 실험은 무작위 데이터만 사용했기 때문에 기본 간격도 최악의 경우(O(n²))까지 나빠지지 않았고 두 방법의 차이가 비교적 작게 나타났다. 정렬된 입력이나 특수한 패턴의 입력에서는 차이가 더 커질 수 있다.

## 4. 결론
- 삽입 정렬은 O(n²)로 증가하여 n = 20,000에서 약 1억 회의 비교가 필요했지만, 쉘 정렬은 약 50~60만 회로 150~190배 적었다.
- 쉘 정렬 안에서도 간격 수열에 따라 성능이 달라지며, Knuth 수열이 기본 간격보다 7.7~15.0% 적은 비교 횟수를 보였다.
- 쉘 정렬의 성능은 알고리즘 자체뿐 아니라 **어떤 gap 수열을 쓰느냐**에 크게 좌우된다.
